# QuickRent — User Manual

Welcome to the QuickRent User Manual. QuickRent is a vehicle rental management platform that allows users to browse, book, and pay for vehicle rentals online, and allows administrators to manage the fleet, bookings, and analytics.

## About QuickRent

QuickRent is built for small-to-medium vehicle rental businesses that need:
- Online booking with real-time availability
- Secure payment processing via Stripe
- Interactive map to find nearby vehicles
- AI-powered chatbot for customer support
- Admin dashboard with analytics

## Tech Stack
- **Backend:** Node.js, Express, MongoDB
- **Frontend:** Next.js 14, TypeScript, Tailwind CSS
- **Payments:** Stripe
- **Notifications:** Firebase
- **AI Chatbot:** Hugging Face API
- **Maps:** Leaflet
